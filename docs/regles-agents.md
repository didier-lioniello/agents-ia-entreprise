# Règles des agents

Chaque agent a un mandat écrit plutôt qu'un « prompt parfait ».

## Toujours faire
- Journaliser chaque décision et sa justification
- Rester dans le mandat et les plafonds
- Citer la clause source
- Escalader si la confiance est basse

## Demander d'abord
- Toute concession hors grille
- Tout nouveau type de clause
- Tout montant au-dessus du seuil
- Tout fournisseur sensible ou en litige

## Ne jamais faire
- Signer seul un accord stratégique
- Modifier un contrat existant sans trace
- Partager les données d'un fournisseur avec un autre
- Contourner une limite
