# Agents IA en entreprise

Proposition de conception de Didier Lioniello (Applied AI Architect) : une négociation fournisseurs confiée à des agents IA, supervisée par niveau de risque (70 % / 20 % / 10 %), avec des règles écrites (toujours faire, demander d'abord, ne jamais faire), des validations humaines et un agent d'évaluation.

C'est un schéma conceptuel, pas l'architecture d'un système réel.
